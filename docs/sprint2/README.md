## Коротко про аудит

| Критерій | Кількість |
|---|---:|
| Однозначність | 4 |
| Повнота | 4 |
| Несуперечливість | 5 |
| Простежуваність | 4 |
| Здійсненність | 4 |
| Тестопридатність | 4 |
| **Разом** | **25** |

У SRS 1.1 після усунення дубля F-120 та додавання S-15 залишилося 40 активних вимог, усі з унікальними ідентифікаторами. Друга вимога зі старим GUI-40 отримала GUI-45. Нумерацію решти вимог не зсували.

У плані 7 рівнів і 24 розглянуті типи; 20 типів застосовні, 4 мають обґрунтоване «ні» (інсталяційне, доступності, відновлення/failover, локалізація).
