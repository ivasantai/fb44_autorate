## 1. Вступ

### 1.1. Призначення

Документ визначає функціональні та нефункціональні вимоги до продукту «АвтоРейт» — вебкаталогу автомобільних марок і моделей із рейтингом, який формують голоси зареєстрованих користувачів. Документ використовують під час підготовки тест-кейсів, модульного тестування і матриці простежуваності. Ідентифікатори F-, GUI-, BL-, P-, S-, U-, D- залишаються опорними.

### 1.2. Обсяг

Вебзастосунок: головна сторінка, реєстрація та вхід, сторінки марок і моделей, голосування з коментарем, профіль користувача. Бізнес-модуль `autorate-module` (Java 17): агрегація рейтингів, перевірка голосів, пошук моделей (основа нової функції «Особистий кабінет і рейтинг тижня»). Інтерфейс модератора та адміністратора, редагування каталогу і мобільний застосунок — поза обсягом версії.

### 1.3. Терміни і скорочення

| Термін | Визначення |
|---|---|
| Марка (make) | Виробник автомобілів; логотип, опис, моделі. |
| Модель (model) | Автомобіль конкретної марки; фото, характеристики, опис, голоси, коментарі. |
| Голос (vote) | Дія авторизованого користувача: оцінка від 1 до 5, вага (репутація), коментар. |
| Рейтинг (rating) | Зважене середнє оцінок 0,0–5,0 за BL-10, округлене до 0,1. |
| Ранг (rank) | Позиція моделі у списку за спаданням рейтингу, після мінімум 3 голосів; при рівності — за назвою. |
| Репутація | Ціле число 1–3, вага голосу при обчисленні рейтингу. |
| Стоп-список | Перелік заборонених слів коментаря, правила — BL-80. |
| Сеанс (session) | Період від успішного входу до Logout або 30 хвилин неактивності. |

### 1.4. Посилання

- Каталог продуктів, продукт П5 «АвтоРейт», підрозділи 7.1, 7.5–7.7.
- Публічний demo: https://buggy.justtestit.org/.
- Модуль: `code/modules/autorate/v1` (Java 17, Maven 3.9, JUnit 5), опис методів у README модуля.
- Вихідна специфікація SRS 1.0: `SRS_05_АвтоРейт.pdf` з матеріалів курсу.

## 2. Загальний опис

### 2.1. Користувачі та ролі

| Роль | Дії |
|---|---|
| Відвідувач | Перегляд каталогу, рейтингу й коментарів, реєстрація та вхід. |
| Зареєстрований користувач | Дії відвідувача, голосування з коментарем, редагування профілю, зміна пароля, вихід. |
| Модератор | Робота з коментарями (інтерфейс поза обсягом поточного demo). |
| Адміністратор каталогу | Додавання й редагування каталогу (інтерфейс поза обсягом demo). |

### 2.2. Середовище

Односторінковий вебзастосунок працює в актуальних Chrome і Firefox на настільних ПК з увімкненим JavaScript. Demo публічний, дані спільні. Java-модуль: JDK 17, Maven 3.9, JUnit 5. Для вимірювання продуктивності та перевірок захищеності використовується лише контрольоване/локальне середовище, не публічний demo.

### 2.3. Обмеження і припущення

- Мова інтерфейсу — англійська; назви полів та тексти повідомлень у вимогах наведені як у UI.
- Голосування доступне лише після входу; тестові облікові записи реєструються самостійно.
- Дані голосів та коментарів на публічному стенді спільні: тести не залежать від абсолютних лічильників.
- Каталог — до 100 марок та 1 000 моделей; параметри P-10/P-20 перевіряють лише в контрольованих умовах.
- Описані модулем репутація й числова оцінка потрібні для нової функції; можливості публічного demo можуть не мати прямого відповідника — це не підстава змінювати SRS без узгодження.

## 5. Вимоги до бізнес-логіки модуля

Модуль `autorate-module` (`ua.kpi.tzyapz.autorate`) містить `RatingAggregator`, `VoteValidator`, `ModelSearch` і DTO `Vote`, `CarModel`. Десяткові величини обчислюються з BigDecimal, округлення до 0,1 — HALF_UP, результат `double`. Для `null` замість колекції — `IllegalArgumentException`.

|---|---|---|
