# Моделі BPMN AutoRate

Продукт: АвтоРейт (П5). Спринт: 1. Дата підготовки: 16.09.2026. Команда: AutoRate QA.
Автори: Асташов Іван, Кінаш Єгор, Рушай Євген, Дарина Поломарьова.

Формат: BPMN 2.0 XML з координатами BPMN DI. Версія комплекту: 1.0.

Відкрийте https://demo.bpmn.io і перетягніть файл .bpmn у редактор. Зміни можна зберегти через Download BPMN. PNG містять відповідні зображення початкової версії; після редагування моделі оновіть експорт.

| Модель | Вихідний файл | Експорт |
|---|---|---|
| Реєстрація і вхід | 01_registration_login.bpmn | 01_registration_login.png |
| Голосування за модель | 02_voting.bpmn | 02_voting.png |
| Модерація коментарів | 03_moderation.bpmn | 03_moderation.png |

R16 і V26 містять внутрішні задачі підпроцесів у XML. Окремі допоміжні файли subprocess_registration_checks.bpmn і subprocess_rating_recalculation.bpmn показують ті самі внутрішні кроки для перегляду. Це деталізація, яка не збільшує норматив трьох бізнес-процесів.

Закриті пули Модератор у BP-02 і Користувач у BP-03 показують лише обмін повідомленнями; їх внутрішній процес тут не розкривається. Система - технічний учасник із таблиці процесів каталогу. Суцільна стрілка - управління, пунктирна з порожнім наконечником - повідомлення, точкова без наконечника - асоціація.
